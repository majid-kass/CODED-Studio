# CODED Color Theme

This skill makes sure every visual produced for CODED and its products uses the right brand color, in the right place, with the right meaning. The palettes below were extracted from the official Figma library and include the usage annotations the design team wrote on each color.

## Brand-wide rule

`#14243F` — **Navy Blue** is the brand-wide constant. It appears across CODED, Unicode, CODED Juniors, Data Science Bootcamp, Academy-X, and Cybersecurity Bootcamp. Treat it as the anchor color whenever a layout needs a "CODED look" regardless of the specific product.

## Typography

Brand typeface is **Neufile Grotesk** (Bold for headlines, Medium for body). When the typeface is unavailable, fall back to a clean geometric sans (Inter, Helvetica Neue, system-ui) — never a serif.

## How to use this skill

1. **Identify the product.** If the brief mentions a product (e.g. "Kuwait Codes deck"), use that palette. If it just says "CODED", use the master CODED palette.
2. **Pick the primary first.** Set the dominant background or hero element to the primary color of that palette.
3. **Pick a secondary.** Pair the primary with the palette's secondary for type / large surfaces.
4. **Use accents sparingly.** Accent / "glow / decorative" colors are for highlights, glows, small icons, gradient halos — never as the dominant color.
5. **Respect the constants.** `#14243F` Navy Blue is the brand anchor — use it whenever a CODED-family deliverable needs gravitas. `#FFFFFF` is the canonical light-mode base for Juniors and Data Science.
6. **Cybersecurity is always a gradient.** Default the background to `linear-gradient(to bottom, #14243F, #00112F)` unless a flat surface is required.
7. **Typography color rules.** White on dark, `#14243F` Navy on light. Use `#1A1A1A` only for formal print typography.
